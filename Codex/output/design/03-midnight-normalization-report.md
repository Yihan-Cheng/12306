## 3. 服务日语义

原始构建脚本将区域外始发或终到的车次裁剪到长三角范围，并把裁剪后首站到达时间、末站出发时间置空。因此，本项目无法从当前数据准确恢复区域外原始始发站的自然日期。

本项目将 `train_run.service_date` 明确定义为：

> 裁剪后长三角区域运行片段起点站的服务日期。

在该日期之后，通过 `day_offset=1` 表示次日到发。这个定义足以支撑长三角单日查询、售票、时间冲突检查和跨午夜行程。

## 4. 回填规则

1. 每个车次裁剪后首站的出发 `day_offset=0`。
2. 如果下一站到达时钟早于前站出发时钟，从下一站到达开始 `day_offset=1`。
3. 如果同一站出发时钟早于到达时钟，该站到达仍为 0，出发开始为 1。
4. 后续停站保持 offset=1。
5. 空到达或空出发时间对应的 offset 也为空。
6. 如果未来数据出现一个区域运行片段多次跨午夜，V003 会直接报错，不会静默产生错误日期。
